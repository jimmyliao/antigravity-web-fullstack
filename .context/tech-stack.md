# 技術棧參考

## 🎨 前端技術

### 核心框架
- **Next.js 15** (App Router) - React 全端框架
- **React 19** - UI 函式庫
- **TypeScript 5.7** - 型別安全

### UI 與樣式
- **TailwindCSS** - Utility-first CSS 框架
- **shadcn/ui** - 可重用 React 元件
- **Radix UI** - 無障礙 UI 元件原語
- **Lucide React** - 圖示庫

### 狀態管理
- **Zustand** - 輕量級狀態管理（推薦）
- **React Context** - 內建狀態管理（小型專案）
- **TanStack Query** - 伺服器狀態管理

### 表單處理
- **React Hook Form** - 表單管理
- **Zod** - Schema 驗證

---

## ⚙️ 後端技術

### Node.js 框架
- **Fastify** - 高性能 Web 框架（推薦）
- **Hono** - 超輕量級框架

### 資料庫
- **PostgreSQL** - 關聯式資料庫（推薦）
- **Drizzle ORM** - 型別安全 ORM
- **Redis** - 快取與 Session

### 認證
- **jose** - JWT 處理
- **@auth/core** - 認證解決方案
- **bcrypt** - 密碼雜湊

---

## 🚀 部署平台

### 前端部署
1. **Vercel**（推薦）- Next.js 最佳整合
2. **Netlify** - 靜態網站與 SSR
3. **Cloudflare Pages** - 全球 CDN

### 後端部署
1. **Railway**（推薦）- 簡單易用
2. **Render** - 免費層級
3. **Fly.io** - 全球分佈式

### 資料庫託管
1. **Neon** - Serverless PostgreSQL
2. **Supabase** - PostgreSQL + 額外功能
3. **PlanetScale** - MySQL（如需要）
